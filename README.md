# Sales & Business Analytics Dashboard

## Project Overview
A Python-based sales analytics project that cleans sales data, calculates business KPIs, performs SQL analysis, creates visualizations, and generates business insights.

## Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- SQL (SQLite)

## Key Analysis
- Revenue and profit analysis
- Regional performance
- Product performance
- Customer analysis
- Category analysis
- Monthly sales trends
- Payment mode analysis
- Business recommendations

## Skills Demonstrated
Data Cleaning | Data Analysis | SQL | Data Visualization | Business Analytics
